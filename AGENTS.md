# Foxsocket agent entry point

Read [the public operating policy](docs/PUBLIC-OPERATING-POLICY.md) for business governance, bounded delegation and public reporting. Its proposed permissions are inactive until explicitly adopted and granted by the owner.

Before work, read [AI-COLLABORATION-POLICY.md](AI-COLLABORATION-POLICY.md), [the project checkpoint](docs/PROJECT-STATE.md), and [CONTRIBUTING.md](CONTRIBUTING.md).

These rules apply equally to all AI contributors. Check latest source/open PRs; declare scope; use isolated branches; preserve unpublished work. Merges and deployments require the user's explicit authorization and no active hold. Do not send unsolicited inter-task messages.

Local-PC work additionally requires the machine's private coordination policy/state and write claim. On the owner's development PC, look in `%USERPROFILE%\Foxsocket-Coordination`. GitHub-only agents must not claim to have read those files without actual access. Keep private PC state out of this repository.
